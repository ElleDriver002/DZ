Баг-репорты по классу StringUtils
================================

1. Метод trim не удаляет пробелы в конце строки
----------------------------------------------
Описание: Согласно документации метод удаляет пробелы только в начале строки.
          Пробелы в конце остаются. Это может быть неожиданным поведением
          для пользователей, привыкших к стандартному str.strip().

Шаги воспроизведения:
  1. Вызвать string_utils.trim("skypro   ")
  2. Получить результат: "skypro   "

Ожидаемый результат (если бы метод работал как strip): "skypro"
Фактический результат: "skypro   "

Серьёзность: Minor
Приоритет: Low
Комментарий: Поведение соответствует документации, но стоит явно указать
             в docstring, что trailing-пробелы не удаляются.


2. Метод contains возвращает True для пустого символа
----------------------------------------------------
Описание: При передаче пустой строки в качестве symbol метод всегда
          возвращает True (потому что "".index("") == 0).

Шаги воспроизведения:
  1. string_utils.contains("hello", "")  → True
  2. string_utils.contains("", "")       → True

Ожидаемый результат: False или ValueError / исключение
Фактический результат: True

Серьёзность: Minor
Приоритет: Medium
Комментарий: Поведение наследуется от str.index(""). Рекомендуется
             добавить явную проверку на пустой symbol.


3. Методы не обрабатывают None
------------------------------
Описание: При передаче None вместо строки все методы падают
          с AttributeError.

Шаги воспроизведения:
  1. string_utils.capitalize(None)
  2. string_utils.trim(None)
  3. string_utils.contains(None, "a")
  4. string_utils.delete_symbol(None, "a")

Ожидаемый результат: понятное исключение TypeError или возврат значения
Фактический результат: AttributeError: 'NoneType' object has no attribute ...

Серьёзность: Major
Приоритет: High
Комментарий: Стоит добавить проверку типа входных данных в начале методов
             или явно задокументировать, что None не поддерживается.
